## Usage

- relancer `php artisan ui:inventory-selects --write` apres ajout ou modification de formulaires
- parametrer les cas specifiques dans `config/ui-selects.php` via `overrides.keys`, `overrides.names` ou `overrides.ids`
- ajouter `data-select-key` sur les selects anonymes qui doivent recevoir un parametrage stable
